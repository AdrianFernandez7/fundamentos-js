# fundamentos-js

Proyecto de la **Actividad 3 - Puesta en marcha del entorno profesional** (DWEC, UT01).

Contiene 21 ejercicios de fundamentos de JavaScript. Cada ejercicio esta en su propia carpeta (`ejercicio-01` ... `ejercicio-21`) con `index.html`, `estilos.css` y `app.js`.

## Como usarlo

1. Abre `index.html` (la portada) en el navegador, o visita el sitio publicado con GitHub Pages.
2. Pulsa en un ejercicio de la lista.
3. Escribe los datos (si hacen falta) y pulsa **Ejecutar**. El resultado sale en la zona "Salida".

## Ejecutar con Node.js

Los ejercicios 1, 2 y 3 tambien funcionan sin navegador:

```
node ejercicio-02/app.js
```

## Herramientas usadas

- Visual Studio Code
- Node.js
- Git y GitHub
- GitHub Pages
